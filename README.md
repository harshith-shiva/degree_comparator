# 🎓 Degree Comparator

A tool to **compare academic degrees side-by-side** based on key factors like duration, eligibility, career paths, skills, and future scope — helping students make informed decisions instead of guessing.

---

## 🚩 Problem Statement

Students often choose degrees based on:
- peer pressure
- incomplete information
- vague career promises

There is **no simple, centralized way** to objectively compare degrees across multiple dimensions.

This project aims to solve that.

---


This project uses C++ primarily to compare different courses in a degree and tells you the correct order of courses to follow to finish your degree

This was primarily a Datastructures project aiming to use different concepts such as DFS, Jaccard similarity, Union ,Intersection , Topological Sorting
